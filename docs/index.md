# Marionette Documentation

Marionette runs `std.Io`-shaped Zig code under deterministic time, disk,
network, allocation, process, and cooperative-scheduling models. The
[README](https://github.com/sb2bg/marionette#readme) contains the introduction
and installation instructions.
